Custom JS Rules Guide

Write JavaScript that runs inside the browser for each DOM element. Return a string to flag it, or null to skip.

Available Variables

VariableTypeDescription
elElementThe DOM element being evaluated
stCSSStyleDeclarationwindow.getComputedStyle(el) — all computed CSS values
rectDOMRectel.getBoundingClientRect() — position and dimensions
areanumberrect.width * rect.height — pre-calculated element area in px²

Return Values

"some text" Flag this element — the string becomes the detail shown in scan results
{ detail: "..." } Same as string, object form for future extensibility
null / undefined Skip this element — no finding recorded

Errors thrown by your script are silently ignored per element so one bad node won't stop the scan.

Typography

typography

Small font size

Flag any text element with a computed font size below 12px.

const fs = parseFloat(st.fontSize);
return fs > 0 && fs < 12 ? `${fs}px font-size` : null;
typography

Line height too tight

Detects paragraphs and headings where line-height is below 1.3× the font size — hard to read.

const tags = ['P','H1','H2','H3','H4','H5','H6','LI'];
if (!tags.includes(el.tagName)) return null;
const fs = parseFloat(st.fontSize);
const lh = parseFloat(st.lineHeight);
if (!fs || !lh) return null;
return lh / fs < 1.3 ? `line-height ${lh.toFixed(1)}px / font ${fs}px` : null;
typography

Heading hierarchy skip

Flags an H3/H4/H5/H6 that has no preceding H2 on the page — broken heading hierarchy hurts accessibility.

const level = parseInt(el.tagName[1]);
if (isNaN(level) || level <= 2) return null;
const prev = document.querySelector(`h${level - 1}`);
return !prev ? `${el.tagName} with no preceding H${level - 1}` : null;
typography

Letter spacing too tight

Flags elements where letter-spacing is below -0.05em — text becomes unreadable when letters overlap.

const ls = st.letterSpacing;
if (ls === 'normal') return null;
const fs = parseFloat(st.fontSize) || 16;
const lsPx = ls.endsWith('em') ? parseFloat(ls) * fs : parseFloat(ls);
return lsPx < -(fs * 0.05) ? `letter-spacing ${ls}` : null;

Color & Contrast

contrast

Low contrast text (approx WCAG AA)

Checks foreground vs background luminance ratio. Flags when below 4.5:1 on text elements.

const tags = ['P','SPAN','H1','H2','H3','H4','H5','H6','A','LI','TD','TH','LABEL','BUTTON'];
if (!tags.includes(el.tagName)) return null;
function lum(c) {
  const m = c.match(/\d+/g);
  if (!m || m.length < 3) return null;
  return m.slice(0,3).map(Number).map(v => {
    v /= 255;
    return v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4;
  }).reduce((s, v, i) => s + v * [0.2126, 0.7152, 0.0722][i], 0);
}
const L1 = lum(st.color), L2 = lum(st.backgroundColor);
if (L1 === null || L2 === null) return null;
const hi = Math.max(L1, L2), lo = Math.min(L1, L2);
const ratio = (hi + 0.05) / (lo + 0.05);
return ratio < 4.5 ? `contrast ${ratio.toFixed(2)}:1 (WCAG AA min 4.5)` : null;
contrast

Invisible text (same color as background)

Detects elements where text color is identical or near-identical to the background — invisible but indexable.

const fg = st.color.match(/\d+/g);
const bg = st.backgroundColor.match(/\d+/g);
if (!fg || !bg || bg[3] === '0') return null;
const diff = Math.abs(+fg[0]-+bg[0]) + Math.abs(+fg[1]-+bg[1]) + Math.abs(+fg[2]-+bg[2]);
return diff < 30 ? `text color ~= background (diff ${diff})` : null;
contrast

White text on white background

Specifically catches white-on-white — a common accidental invisibility pattern.

const fg = st.color.match(/\d+/g);
const bg = st.backgroundColor.match(/\d+/g);
if (!fg || !bg) return null;
const fgWhite = +fg[0] > 240 && +fg[1] > 240 && +fg[2] > 240;
const bgWhite = +bg[0] > 240 && +bg[1] > 240 && +bg[2] > 240;
return fgWhite && bgWhite ? 'white text on white background' : null;

Images & Media

images

Missing alt text on images

Flags <img> elements with no alt attribute or an empty alt that isn't intentionally decorative.

if (el.tagName !== 'IMG') return null;
const alt = el.getAttribute('alt');
if (alt === null) return 'img missing alt attribute';
if (alt.trim() === '' && el.getAttribute('role') !== 'presentation') return 'img has empty alt (not marked decorative)';
return null;
images

Oversized images (width > 1200px rendered)

Flags images rendered wider than 1200px — usually a sign of missing max-width or an unoptimized asset.

if (el.tagName !== 'IMG') return null;
return rect.width > 1200 ? `rendered at ${Math.round(rect.width)}px wide` : null;
images

Broken image (natural size is 0)

Detects images that loaded but have zero natural dimensions — indicative of a broken or 1×1 tracking pixel used as a layout element.

if (el.tagName !== 'IMG') return null;
if (!el.complete) return null;
return (el.naturalWidth === 0 || el.naturalHeight === 0) ? `broken image (natural ${el.naturalWidth}×${el.naturalHeight})` : null;
images

Stretched / distorted image

Compares the rendered aspect ratio to the natural aspect ratio. A large difference means the image is being stretched.

if (el.tagName !== 'IMG' || !el.naturalWidth || !el.naturalHeight) return null;
const natRatio = el.naturalWidth / el.naturalHeight;
const rendRatio = rect.width / rect.height;
if (!rendRatio) return null;
const diff = Math.abs(natRatio - rendRatio) / natRatio;
return diff > 0.15 ? `distorted image (natural ${el.naturalWidth}×${el.naturalHeight}, rendered ${Math.round(rect.width)}×${Math.round(rect.height)})` : null;

Accessibility

a11y

Interactive element with no accessible name

Buttons and links must have visible text, aria-label, or aria-labelledby. Flags those that don't.

if (el.tagName !== 'BUTTON' && el.tagName !== 'A') return null;
const text = (el.textContent || '').trim();
const aria = el.getAttribute('aria-label') || el.getAttribute('aria-labelledby') || el.getAttribute('title');
return !text && !aria ? `${el.tagName.toLowerCase()} has no accessible name` : null;
a11y

Input without associated label

Form inputs (excluding hidden/submit/button types) should have a <label>, aria-label, or placeholder.

if (el.tagName !== 'INPUT') return null;
const type = (el.getAttribute('type') || '').toLowerCase();
if (['hidden','submit','button','image','reset'].includes(type)) return null;
const id = el.id;
const hasLabel = id && document.querySelector(`label[for="${id}"]`);
const hasAria = el.getAttribute('aria-label') || el.getAttribute('aria-labelledby');
const hasPlaceholder = el.getAttribute('placeholder');
return !hasLabel && !hasAria && !hasPlaceholder ? 'input has no label, aria-label, or placeholder' : null;
a11y

Tiny tap target (below 44×44px)

WCAG 2.5.5 recommends at least 44×44px for interactive controls. Flags buttons, links, and inputs that are too small.

const tags = ['BUTTON','A','INPUT','SELECT','LABEL'];
if (!tags.includes(el.tagName)) return null;
if (rect.width === 0 || rect.height === 0) return null;
if (rect.width < 44 || rect.height < 44) {
  return `tap target ${Math.round(rect.width)}×${Math.round(rect.height)}px (min 44×44)`;
}
return null;
a11y

Role=button without keyboard handler

Non-button elements using role="button" must also have a tabindex and keyboard listeners. Detects the most common missing piece.

if (el.getAttribute('role') !== 'button') return null;
if (el.tagName === 'BUTTON' || el.tagName === 'A') return null;
const tabindex = el.getAttribute('tabindex');
return tabindex === null ? 'role=button element missing tabindex' : null;

Layout & Spacing

layout

Element overflowing viewport width

Flags elements whose right edge extends beyond the viewport — causes horizontal scrollbar on mobile.

const vw = window.innerWidth;
if (rect.left < 0 || rect.width === 0) return null;
return rect.right > vw + 2 ? `overflows viewport by ${Math.round(rect.right - vw)}px` : null;
layout

Fixed pixel width on containers

Detects divs and sections with explicit pixel widths above 300px — these can break fluid layouts on small screens.

if (!['DIV','SECTION','ARTICLE','MAIN','ASIDE','HEADER','FOOTER'].includes(el.tagName)) return null;
const w = el.style.width || st.width;
if (!w || !w.endsWith('px')) return null;
const px = parseFloat(w);
return px > 300 ? `fixed width ${px}px on ${el.tagName.toLowerCase()}` : null;
layout

Absolute positioning outside parent

Flags absolutely-positioned elements whose bounding box extends outside their positioned ancestor — often an unnoticed overflow.

if (st.position !== 'absolute') return null;
const parent = el.offsetParent;
if (!parent) return null;
const pr = parent.getBoundingClientRect();
const overflow = rect.right > pr.right + 2 || rect.bottom > pr.bottom + 2 || rect.left < pr.left - 2 || rect.top < pr.top - 2;
return overflow ? `absolute element overflows its positioned parent` : null;
layout

Zero-height clickable area

Buttons or links collapsed to zero height — present in DOM but not clickable.

if (el.tagName !== 'BUTTON' && el.tagName !== 'A') return null;
return rect.height < 1 ? `${el.tagName.toLowerCase()} has zero rendered height` : null;

Content Quality

content

Lorem ipsum placeholder text

Detects any element whose visible text contains "Lorem ipsum" — a common sign of unfinished pages.

const text = el.textContent || '';
return /lorem\s+ipsum/i.test(text) ? 'contains Lorem ipsum placeholder text' : null;
content

TODO / FIXME in visible text

Finds developer notes accidentally left in production copy.

const t = (el.textContent || '').trim();
const m = t.match(/\b(TODO|FIXME|HACK|XXX|PLACEHOLDER)\b/i);
return m ? `"${m[0]}" in visible text` : null;
content

Empty heading tags

Heading elements with no text content confuse screen readers and break page outline.

if (!/^H[1-6]$/.test(el.tagName)) return null;
return !(el.textContent || '').trim() ? `empty ${el.tagName} tag` : null;
content

Long paragraph without line break (>500 chars)

Very long dense paragraphs reduce readability. Flags P elements with more than 500 visible characters.

if (el.tagName !== 'P') return null;
const len = (el.textContent || '').trim().length;
return len > 500 ? `paragraph is ${len} characters — consider breaking it up` : null;

Links & Buttons

links

Link opens in new tab without warning

Links that open in a new tab should inform users — commonly done with an icon or aria-label. Flags those that don't.

if (el.tagName !== 'A') return null;
if (el.getAttribute('target') !== '_blank') return null;
const hasWarning = el.getAttribute('aria-label') || el.querySelector('[aria-label]') || el.querySelector('[title*="new"]');
return !hasWarning ? 'opens in new tab without accessible indication' : null;
links

"Click here" link text

Generic link text like "click here" or "read more" is meaningless when read in isolation by screen readers.

if (el.tagName !== 'A') return null;
const text = (el.textContent || '').trim().toLowerCase();
const bad = ['click here','here','read more','more','learn more','this','link'];
return bad.includes(text) ? `non-descriptive link text: "${text}"` : null;
buttons

Submit button outside a form

Submit inputs/buttons not inside a <form> won't function as expected when JS is disabled.

if (el.tagName !== 'BUTTON' && el.tagName !== 'INPUT') return null;
const type = (el.getAttribute('type') || '').toLowerCase();
if (type !== 'submit') return null;
return !el.closest('form') ? 'submit button is not inside a form element' : null;

Visibility

visibility

Off-screen element with content

Detects elements positioned far off-screen (common SEO spam pattern or debug artifact) that have non-empty text.

if (!el.textContent.trim()) return null;
if (rect.width === 0 || rect.height === 0) return null;
const offscreen = rect.right < -200 || rect.left > window.innerWidth + 200 || rect.bottom < -200 || rect.top > window.innerHeight + 3000;
return offscreen ? `off-screen element at (${Math.round(rect.left)},${Math.round(rect.top)})` : null;
visibility

Low opacity element

Elements with opacity below 0.3 that contain text — may appear invisible but are still in the DOM.

const op = parseFloat(st.opacity);
if (isNaN(op) || op >= 0.3) return null;
if (!(el.textContent || '').trim()) return null;
return `opacity ${op} on element with text content`;

Performance

performance

Inline style attribute with many properties

Elements with excessively long inline style strings (15+ properties) are hard to maintain and slow style recalculation.

const style = el.getAttribute('style') || '';
const count = style.split(';').filter(s => s.trim()).length;
return count > 15 ? `${count} inline style properties — consider extracting to a class` : null;
performance

GIF image (consider video/WebP)

GIFs are far larger than equivalent videos or WebP animations. Flags any <img> loading a .gif URL.

if (el.tagName !== 'IMG') return null;
const src = el.getAttribute('src') || el.src || '';
return /\.gif(\?|$)/i.test(src) ? `GIF image: ${src.split('/').pop()}` : null;
performance

Background image on large element (potential LCP)

Large background-image divs (hero sections) should use <img> for LCP optimisation. Flags divs with a background-image and area over 100,000 px².

if (el.tagName !== 'DIV' && el.tagName !== 'SECTION') return null;
if (area < 100000) return null;
const bg = st.backgroundImage;
if (!bg || bg === 'none') return null;
return `large background-image on ${el.tagName.toLowerCase()} (${Math.round(rect.width)}×${Math.round(rect.height)}) — consider <img> for LCP`;
