Complete guide to using and extending BrowserHub.

Getting Started

1

Install dependencies

Run npm install in the WebSite directory to install Express, Socket.io, and Playwright.

2

Install browser

Run npm run setup to download Playwright's Chromium browser binary.

3

Start the server

Run npm start to start the server. Open http://localhost:3000 in your browser.

4

Run your first scan

On the Dashboard, enter a sitemap URL (e.g. https://your-site.com/sitemap.xml) and click Start Scan.

How It Works

BrowserHub uses Playwright (headless Chromium) to visit each URL in your sitemap or URL list. For each page, it evaluates all visible DOM elements against your configured detection rules using window.getComputedStyle() — the same CSS values a browser would render. Findings are streamed back in real-time via WebSocket.

The scanner processes URLs sequentially (one page at a time) to avoid overloading target servers. Each scan result is persisted to a local JSON file and is always accessible via the Results page.

Rules System

Rules are stored in data/store.json and loaded before each scan. Two rule types are supported:

  • background-color — matches elements by computed background RGB. Configure minR/G/B (lower bound) and optional maxR/G/B (upper bound), plus minArea to ignore small elements.
  • custom-js — run any JavaScript inside the live page context. Receives el, st, rect, area. Return a string to flag the element or null to skip. See the Custom JS Guide for 20+ examples.

Each DOM element matches at most one rule — the first matching rule wins (rules are evaluated in order).

// background-color rule
{
  "id": "white-bg",
  "name": "Large White Background",
  "type": "background-color",
  "enabled": true,
  "severity": "high",
  "config": { "minR": 240, "minG": 240, "minB": 240, "minArea": 50000, "label": "White BG" }
}

// custom-js rule
{
  "id": "rule-1234",
  "name": "Small Font Size",
  "type": "custom-js",
  "enabled": true,
  "severity": "medium",
  "config": {
    "script": "const fs = parseFloat(st.fontSize);\nreturn fs > 0 && fs < 12 ? `${fs}px font-size` : null;",
    "minArea": 0,
    "label": "Small Font"
  }
}

REST API

Method Path Description
GET /api/scans List all scans (most recent first)
GET /api/scans/:id Get full scan with findings
POST /api/scans Start a new scan { type, input }
POST /api/scans/:id/cancel Cancel a running scan
DELETE /api/scans/:id Delete a scan record
GET /api/rules Get all detection rules
PUT /api/rules Save rules array (full replace)

WebSocket Events

  • join:scan(id) — subscribe to real-time events for scan ID
  • scan:status — scan status changed
  • scan:urls — URL count resolved
  • scan:progress — page scan started (current, total, url, percent)
  • scan:finding — new finding recorded
  • scan:page-error — page failed to load
  • scan:complete — scan finished (status, stats)
  • scan:error — fatal scan error
